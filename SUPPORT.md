# Support Policy

WebStreamr Legacy is community maintained on a best-effort basis.

## In Scope

- self-host installation and Docker startup issues;
- build and test failures on supported Node versions;
- extractor or source regressions with sanitized examples;
- documentation fixes;
- safe maintenance work that keeps the archived project usable.

## Out Of Scope

- support for the archived public WebStreamr instance;
- private hosted-service incidents;
- requests to expose a public media relay;
- issues containing credentials, cookies, tokens, private endpoint URLs, or
  personal data;
- broad "find every source for this title" requests without technical evidence.

## Useful Bug Reports

Please include:

- WebStreamr Legacy version or commit;
- Node version and deployment target;
- Docker image tag, if using Docker;
- sanitized request id shape, for example `tt1234567` or
  `tt1234567:1:1`;
- expected result and actual result;
- sanitized logs with secrets removed.
